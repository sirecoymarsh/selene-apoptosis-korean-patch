## 추가·변경 사항

이 절은 원본 게임(Steam판)과 비교해 이 패치가 무엇을 더하고 바꾸는지 커밋 기록, 릴리스 노트, `manifest.json`, `VERIFICATION.md`, `CREDITS.txt`를 근거로 정리한 것입니다. 괄호 안은 근거(커밋 해시, 파일, 릴리스 태그)이며, 확실하지 않은 내용은 「(추정)」으로 표시했습니다.

### 번역 범위

- **번역 기준**: 영어 원문을 기준으로 교정·윤문한 유저 한국어 번역입니다. 사용자가 방향을 잡고 Claude, Gemini, Codex로 작업한 결과를 종합했으며, 한 모델이 한 번에 옮긴 번역이 아닙니다 (`manifest.json`의 `language_contract`, `translation_provenance`, `CREDITS.txt`).
- **공식 번역과 따로 둠**: 게임에 원래 있던 공식 한국어는 지우지 않고 **한국어(원본)**(`tl/korean_original`)으로 옮겼고, 이 패치의 번역은 **한국어(유저)**(`tl/korean`)로 넣었습니다. 기존에 「한국어」를 고른 설정은 유저 번역을 가리킵니다. 다른 14개 언어도 그대로 고를 수 있습니다 (`manifest.json`, v1.1).
- **대사**: 장(chapter) 번역 파일 36개를 유저 번역으로 넣었고, 같은 36개를 공식 번역 칸에도 따로 넣었습니다 (`game/tl/korean/chapters/`, `game/tl/korean_original/chapters/`).
- **UI·시스템 문자열**: 공통 문자열(`common`), 화면(`screens`, `screens_custom`), 도전 과제(`achievements`), 인물 이름(`characters`), 결말 이름(`endings`), TV 장면(`tv`) 번역이 들어 있습니다 (`game/tl/korean/scripts/`).
- **그림 글자**: 막간 요리쇼 제목 카드 3장(`THEATRE.png`, `howtobake.png`, `presents.png`)을 새로 만든 한국어 그림으로 바꿨습니다 (`game/tl/korean/images/fx/theatre/`, `CREDITS.txt`).
- **음악 곡목**: 감상 화면의 음악 33곡 곡목 옆 괄호에 한국어 뜻을 적었습니다 (v1.3).
- **DLC**: DLC 장면 번역은 DLC(`patch.rpa`)가 따로 설치돼 있을 때만 쓰입니다. 패치에 DLC 자체나 해금 기능은 없습니다 (`manifest.json`의 `optional_archive`).
- **글꼴**: 한국어(원본)과 한국어(유저)에 쓰는 글꼴 설정과 글자 보충 스크립트가 들어 있습니다(`selene_dual_korean_fonts.rpyc`, `tl/korean/selene_ko_glyphs.rpyc`). 무엇을 어떻게 바꾸는지는 저장소에 적혀 있지 않습니다 (추정: 두 한국어 칸에 맞는 글꼴 지정과 빠진 글자 보충).

### 편의 기능 (원판에 없는 기능)

- **갈림길 (F6)**: 이야기 지도(흐름도)입니다. 이번 회차에 실제로 지나온 경로는 금색, 고른 길잡이 경로는 하늘색으로 빛나고, 결말 번호와 도전 과제가 풀리는 지점을 보여 줍니다. 선택 기록이 없는 오래된 세이브의 과거 경로는 추정해 채우지 않습니다. 선택·경로 추적 상태는 이후 저장에 같이 기록됩니다. 도전 과제나 결말을 강제로 풀지 않습니다 (`selene_ko_flowchart.rpyc`, v1.1).
- **해설 (F7)**: 문학·신화·영화·TV 출전 해설, 진행도에 따라 열리는 해설, 따로 표시하는 커뮤니티 해석, 장면 안내(**끔 / 한 줄 / 자세히**)가 있습니다. v1.2 기준 해설 134편, 대사 연결 1,269곳입니다. 해설에 쓰는 사진·그림은 위키미디어 공용 자료와 직접 그린 도해(카메라 옵스큐라, 간섭계, 세 모습의 여신)이고, 출처는 `CREDITS.txt`에 있습니다 (`selene_ko_commentary.rpyc`, v1.1, v1.2 `VERIFICATION.md`).
- **감상 (F8)**: 메인 메뉴 오른쪽 「감상 ‣」로 들어가는 CG 모드와 음악 모드입니다. CG 모드는 이야기 속 CG(움직이는 CG 포함)를 장면별로 모아 크게 보여 주고, 음악 모드는 게임 음악 33곡을 들려 주며 「이어 듣기」로 다음 곡까지 재생합니다. 게임에서 이미 본 CG와 들은 곡만 열리고, 아직 안 열린 칸은 「?」로 보입니다. 감상 화면은 세이브나 기록에 아무것도 쓰지 않습니다. 성인 DLC 그림 칸은 DLC가 설치돼 있을 때만 생깁니다 (`selene_ko_extras.rpyc`, 썸네일 JPG 27개, v1.3).
- 갈림길과 해설은 **한국어(유저)**에서만 보이고, **한국어(원본)**을 고르면 숨겨집니다.

### 설치·제거 방식

- **대상 판본**: Steam 앱 1398210, 빌드 24870432, Windows판입니다. 확인한 원본 아카이브 4개(`scripts.rpa`, `archive.rpa`, `images.rpa`, DLC `patch.rpa`)의 SHA-256이 `manifest.json`에 있습니다. 다른 빌드, 다른 모드와 같이 쓰는 경우, 다른 운영체제는 확인하지 않았습니다.
- **방식**: 자동 설치기 없이 ZIP 안의 `game` 폴더를 게임의 `game` 폴더에 합쳐 덮어쓰는 방식입니다. 원본 `.rpa` 아카이브와 실행 파일은 바꾸지 않고, 컴파일된 Ren'Py 스크립트(`.rpyc`)와 그림을 더하거나 덮어씁니다. 설치 스크립트가 원본 해시를 확인하지는 않습니다.
- **파일 수**: v1.3은 125개(스크립트 95개, PNG 3개, 감상 썸네일 JPG 27개)입니다. v1.1·v1.2는 97개(스크립트 94개, PNG 3개)였습니다 (`manifest.json`, `VERIFICATION.md`).
- **백업·복구**: 설치 전에 `game` 폴더 전체를 게임 밖에 직접 백업합니다. 번역만 되돌리려면 **한국어(원본)**을 고르면 됩니다. 완전히 되돌리려면 `manifest.json`에 적힌 파일만 지우고 백업을 되돌려 놓습니다. Steam 무결성 확인만으로는 새로 더해진 파일이 지워지지 않습니다.
- **누적 패치**: v1.1부터 모든 판이 누적본이라 이전 판을 먼저 설치할 필요가 없고, 이전 판 위에 그대로 덮어써도 됩니다.
- **세이브**: 기존 세이브를 지우거나 바꾸지 않습니다. 갈림길용 선택 기록은 이후 저장에 같이 들어갑니다.
- **배포에서 뺀 것**: 원본 아카이브·실행 파일, DLC와 해금 도구, 세이브와 계정 정보, 시험·초기화용 추가 기능, 내부 소스·작업 기록 (`manifest.json`의 `excluded`).

### 알려진 문제

- 모든 장면을 처음부터 끝까지 다시 플레이해 확인한 것은 아닙니다. 배포·기동·주요 기능까지만 확인했습니다 (`VERIFICATION.md`).
- 언어를 바꿔도 이미 쌓인 백로그의 지난 문장은 모두 다시 번역되지는 않습니다.
- 해설 속 추정과 커뮤니티 해석은 제작자가 확정한 정답이 아닙니다. 진행 기록이 이미 있는 PC에서는 해설이 더 많이 열려 보일 수 있습니다.
- 갈림길은 선택 기록이 없는 오래된 세이브의 과거 경로를 보여 주지 못합니다.
- Steam 빌드 24870432 외의 빌드, Windows 외의 운영체제, 다른 모드와의 병용은 확인하지 않았습니다.
- README가 안내하는 `FILES_SHA256.txt`는 이 저장소에는 없습니다. 배포 ZIP 안에 들어 있는 것으로 보입니다 (추정). 저장소에는 ZIP 해시만 적은 `SHA256SUMS.txt`가 있습니다.

## 설치 — 게임을 끈 다음 진행

1. Steam 라이브러리 → 게임 우클릭 → **관리 → 로컬 파일 보기**로 `Selene.exe`가 있는 폴더를 엽니다.
2. **현재 `game` 폴더 전체를 게임·패치 폴더 바깥의 별도 백업 폴더에 복사합니다.**
   기존 패치 사용자는 현재 상태를 복구하려면 이 백업이 필요합니다. 별도 AppData 세이브도 따로 보관해 두면 좋습니다.
3. ZIP을 별도 폴더에 풉니다. 안의 `Selene_Apoptosis_Korean_Patch_v1.3/game` 폴더를
   `Selene.exe`가 있는 폴더에 복사하여 기존 `game` 폴더와 **합칩니다**. 중복 파일은 덮어씁니다.
   `game/game` 형태로 중첩되면 잘못 설치한 것입니다.
4. 실행 후 환경 설정 → 언어 → **한국어(유저)**를 선택합니다.
   **한국어(원본)**을 고르면 공식 번역으로 바뀌고 유저 갈림길·해설은 숨겨집니다.

자동 설치기가 아닌 수동 덮어쓰기 패치입니다. 덮어쓰기 전에 버전과 백업을 직접 확인하세요.
다른 모드 또는 편집용 `.rpy` 소스가 같은 경로에 있다면 그대로 병합하지 마세요.
이 패치의 정확한 대상 경로는 `manifest.json`의 `files` 및 `FILES_SHA256.txt`에 있습니다.

  백업에 없던 이번 패치의 신규 파일도 남지 않도록 목록과 대조하세요.

## 이용 방법과 범위

- 갈림길: F6 또는 메뉴의 **갈림길**. 금색은 확인 가능한 이번 회차 경로, 하늘색은 선택한 길잡이 경로입니다.
  오래된 세이브에 선택 기록 자체가 없으면 과거 경로를 확정할 수 없으며 이를 추정하여 채우지 않습니다.
  선택·경로 추적용 상태는 이후 저장에 함께 기록됩니다. 도전 과제나 결말을 강제로 해금하지 않습니다.
- 해설: F7 또는 메뉴의 **해설**. 장면 안내는 **끔 / 한 줄 / 자세히** 중 선택합니다.
  해설은 비공식 읽을거리입니다. 추정과 커뮤니티 해석은 제작자가 확정한 정답이 아닙니다.
  읽은 대목에 따라 열리므로, 이미 진행 기록이 있는 PC에서는 더 많은 해설이 보일 수 있습니다.
- 언어를 전환해도 이미 쌓인 백로그의 과거 문장이 모두 소급 번역되지는 않습니다.
- 기존 세이브는 삭제·변환하지 않습니다. 배포 ZIP에는 개발용 기록 초기화 도구도 포함하지 않습니다.

## 파일 확인·출처

- `manifest.json`: 대상 게임과 125개 패치 파일의 크기·SHA-256.
- `FILES_SHA256.txt`: 설명서·manifest를 포함한 배포 파일 SHA-256(목록 자신의 해시는 제외).
- `CREDITS.txt`: 해설 사진·그림의 저작자와 이용 조건.
- 오역·버그 제보: 이 저장소의 Issues. 문제가 난 문장/장면과 스크린샷을 첨부해 주세요.
  계정 정보와 개인 세이브는 공개 Issue에 올리지 않아도 됩니다.
