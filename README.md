# Selene ~Apoptosis~ 비공식 한국어 패치 v1.1

Steam Windows판용 누적 패치 · 2026-10-09

## 다운로드

GitHub Releases에서 `Selene_Apoptosis_Korean_Patch_v1.1.zip`을 받으세요.
GitHub 자동 생성 `Source code` 압축에는 게임 패치가 들어 있지 않습니다.

## 포함 내용

- 영어 원문을 기준으로 교정·윤문한 유저 한국어 번역.
- 환경 설정의 **한국어(원본) / 한국어(유저)** 선택. 기존 한국어 설정은 유저 번역을 가리킵니다.
- **갈림길(F6)**: 이번 회차 경로의 금색 효과, 길잡이의 하늘색 효과, 결말 번호와 도전 과제 해금 지점.
- **해설(F7)**: 문학·신화·영화·TV 출전, 진행도에 따라 열리는 해설, 별도 커뮤니티 해석, 선택형 장면 안내.
- 막간 요리쇼 제목 카드 3장 한국어화.
- 최신 선택지·호프 말투·인물 지칭 교정, 페르시안 고양이 참고 사진과 카메라 옵스큐라 해설.

이 패치만으로 게임을 실행할 수 없습니다. 게임 실행 파일·원본 아카이브·DLC·세이브는 포함하지 않습니다.
DLC 장면의 번역은 해당 DLC가 별도로 설치된 경우에만 사용됩니다. 콘텐츠 해금 기능은 없습니다.

## 지원 버전

- Steam 앱 1398210, **빌드 24870432**, Windows에서 확인했습니다.
- 기준 `game/scripts.rpa` SHA-256: `9d214c2fa033f2c1c785efa9b544d729e4c441ed8815012e406d0c54c2a8a274`
- 다른 빌드·다른 모드와의 병용은 검증하지 않았습니다. 업데이트 후에는 호환 버전의 패치를 사용하세요.
- 97개 파일(컴파일된 Ren'Py 스크립트 94개, PNG 3개)을 추가하거나 기존 패치 파일에 덮어씁니다.
- 원본 한국어와 다른 14개 언어는 계속 선택할 수 있습니다. 다른 운영체제는 이번 배포에서 실행 검증하지 않았습니다.

## 설치 — 게임을 끈 다음 진행

1. Steam 라이브러리 → 게임 우클릭 → **관리 → 로컬 파일 보기**로 `Selene.exe`가 있는 폴더를 엽니다.
2. **현재 `game` 폴더 전체를 게임·패치 폴더 바깥의 별도 백업 폴더에 복사합니다.**
   기존 패치 사용자는 현재 상태를 복구하려면 이 백업이 필요합니다. 별도 AppData 세이브도 따로 보관해 두면 좋습니다.
3. ZIP을 별도 폴더에 풉니다. 안의 `Selene_Apoptosis_Korean_Patch_v1.1/game` 폴더를
   `Selene.exe`가 있는 폴더에 복사하여 기존 `game` 폴더와 **합칩니다**. 중복 파일은 덮어씁니다.
   `game/game` 형태로 중첩되면 잘못 설치한 것입니다.
4. 실행 후 환경 설정 → 언어 → **한국어(유저)**를 선택합니다.
   **한국어(원본)**을 고르면 공식 번역으로 바뀌고 유저 갈림길·해설은 숨겨집니다.

자동 설치기가 아닌 수동 덮어쓰기 패치입니다. 덮어쓰기 전에 버전과 백업을 직접 확인하세요.
다른 모드 또는 편집용 `.rpy` 소스가 같은 경로에 있다면 그대로 병합하지 마세요.
이 패치의 정확한 대상 경로는 `manifest.json`의 `files` 및 `FILES_SHA256.txt`에 있습니다.

## 복구 / 제거

- 번역만 되돌리려면 파일을 지우지 않고 **한국어(원본)**을 선택하면 됩니다.
- 설치 직전 상태로 정확히 되돌리려면 먼저 언어를 English로 바꾸고 게임을 종료하세요.
  `manifest.json`에 적힌 **97개 파일만** 설치 위치에서 제거한 뒤, 2단계 백업의 내용을 같은 위치에 복사합니다.
  백업에 없던 이번 패치의 신규 파일도 남지 않도록 목록과 대조하세요.
- `game`, `tl`, `saves` 폴더 전체를 삭제하지 마세요. `*.rpa`, 실행 파일, 기존 세이브는 제거 대상이 아닙니다.
- Steam의 무결성 확인만으로는 새로 추가된 패치 파일이 제거되지 않습니다.
- 플레이 후에 복구한다면 백업의 오래된 `saves` 폴더로 최신 세이브를 덮어쓰지 말고 현재 세이브를 보존하세요.
- 복구 뒤 원본에서는 패치 전용 갈림길 표시는 사용할 수 없습니다.

## 이용 방법과 범위

- 갈림길: F6 또는 메뉴의 **갈림길**. 금색은 확인 가능한 이번 회차 경로, 하늘색은 선택한 길잡이 경로입니다.
  오래된 세이브에 선택 기록 자체가 없으면 과거 경로를 확정할 수 없으며 이를 추정하여 채우지 않습니다.
  선택·경로 추적용 상태는 이후 저장에 함께 기록됩니다. 도전 과제나 결말을 강제로 해금하지 않습니다.
- 해설: F7 또는 메뉴의 **해설**. 장면 안내는 **끔 / 한 줄 / 자세히** 중 선택합니다.
  해설은 비공식 읽을거리입니다. 추정과 커뮤니티 해석은 제작자가 확정한 정답이 아닙니다.
  읽은 대목에 따라 열리므로, 이미 진행 기록이 있는 PC에서는 더 많은 해설이 보일 수 있습니다.
- 언어를 전환해도 이미 쌓인 백로그의 과거 문장이 모두 소급 번역되지는 않습니다.
- 기존 세이브는 삭제·변환하지 않습니다. 배포 ZIP에는 개발용 기록 초기화 도구도 포함하지 않습니다.
